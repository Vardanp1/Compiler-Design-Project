ErrorBuddy

A beginner compiler, written in C++17 with only the standard library, that explains its own errors: the right line, plain words, one concrete fix.

The problem

A beginner forgets one semicolon on line 2. gcc reports program.c:3:5: error: expected ',' or ';' before 'printf': the wrong line, grammar words, and no fix. ErrorBuddy reports line 2, says what rule was broken in plain English, and gives one concrete thing to type.

How it works

Source text goes through five phases. Phases 2 to 4 run together in one pass of the parser (syntax-directed translation). Any phase can throw a CompileError { line, phase, message, suggestion }; the driver prints it and no intermediate code is shown.

1 · lexer.cppLexical analysis

Hand-written scanner. Tokens carry their line number. Rejects @, 2nd and numbers above INT_MAX.

2 · parser.cppSyntax analysis

Recursive descent, one function per grammar rule. Precedence and left-associativity come from the grammar.

3 · parser.cppSemantic analysis

Symbol table of names, declaration lines and values: undeclared, redeclared, self-use, division by zero, overflow.

4 · parser.cppThree-address code

At most one operator per instruction, temporaries t1, t2… that never clash with user names.

5 · all phasesFriendly errors

Looks at nearby tokens to name the cause, and uses edit distance for "Did you mean…?" hints.

The language

A small C-like language, kept small on purpose so every phase is complete. Every variable is an int with a starting value; + - * / with precedence and parentheses; print; // comments. Compilation stops at the first error.

// examples/valid.txt
int age = 20;
int score = 10;
score = score + age * 2;
int bonus = (score - 5) / 5;
print score;
print bonus * (age + 1);

Run it yourself

$ git clone https://github.com/Vardanp1/Compiler-Design-Project.git
$ cd Compiler-Design-Project
$ make                              # g++ -std=c++17
$ ./errorbuddy examples/valid.txt --tokens
$ make test                         # 10 examples vs expected output
$ make web                          # http://localhost:8795
$ python3 case_study/run_study.py   # ErrorBuddy vs gcc
